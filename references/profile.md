# 使用配置（profile）

> **这是模板。** 首次使用时把下面每一处 `<...>` 换成你自己的实际情况，填完即生效。
> 填完这份文件，技能就不再需要问你这五个问题；没填的话，技能会在开工前先问你。
> 换机器、换品牌时也只需要改这一个文件。

## 3. 人物形象（可选）

片子里要不要出现你自己的固定形象？两种情况二选一：

**A. 不需要人物** —— 写"无"，技能不会擅自加人。

**B. 需要固定人物** —— 填下表，并把参考图放在本技能目录下的 `assets/ip/` 里：

| 项 | 值 |
| --- | --- |
| 形象名 | `<例如：小明 / 工作室吉祥物>` |
| 参考图 | `assets/ip/<文件名>.png`（正面或三视图，越清晰越好） |
| 形象类型 | `<真人出镜抠像 / Q 版卡通 / 3D 插画 / 吉祥物>` |
| 不可变特征 | `<脸型、发型、眼镜、服装、配色——逐条写清楚，禁止漂移>` |
| 出现比例 | `<偶尔客串 / 每支片都有 / 只做片尾落款>` |

没填参考图就当作 A（无人物）。人物一旦定下，后续每支片都用同一份参考图和同一段特征描述，
不允许逐片"重新想象"。

## 5. 本机运行环境

先跑一次自检，把结果抄在这里，之后就不用反复试错：

```bash
bash <skill>/scripts/env_check.sh
```

| 项 | 值 |
| --- | --- |
| Python | `<python3 --version；跑配乐/审计需要 numpy + Pillow>` |
| Node | `<node --version；>= 18>` |
| Chrome | `<自检输出的路径；找不到就装 Chrome 或用 npx puppeteer browsers install chrome，再把路径写这里>` |
| ffmpeg | `<which ffmpeg>` |
| GPU 模式 | `<software（默认，最稳）/ hardware（更快，部分机器会挂起）>` |

实测踩过的坑（通用，建议保留）：

- `HYPERFRAMES_BROWSER_PATH` 可指定渲染用浏览器；渲染日志写文件后轮询，别用管道（会被缓冲吞掉）。
- GSAP 必须本地化到 `film/assets/gsap.min.js`，用 CDN 离线渲染会白屏。
- 沙箱环境跑 Chrome/渲染常需关沙箱，否则浏览器起不来。
- ES Module 不认 `NODE_PATH`：把 `node_modules` 软链到工程目录，或写绝对 import 路径。
- 脚本里取当前目录用 `fileURLToPath(import.meta.url)`，不要用 `new URL(...).pathname`（中文路径会被 URL 编码）。

## 6. 交付习惯

- 成片位置：`<工程根目录>`，命名 `<品牌或主题>_<版本>.mp4`
